Why Modern DuoBar Stands Apart

A feature-by-feature comparison against the original baseline.

Capability Original DuoBar (v1.0.0) Modern DuoBar (vibe2code)
📶 Wi-Fi Network Picker ❌ Static name only ✅ Live CoreWLAN scan, signal strength bars, WPA locks & direct password join
🎧 Audio Output Selector ❌ Static label only ✅ Interactive Core Audio device switcher (AirPods, Speakers, HDMI, USB DAC)
⚡ Wi-Fi Power Control ❌ None ✅ 1-click Wi-Fi module power toggle (On / Off) directly from the popover
🪟 Settings Window Design ⚠️ Basic opaque form ✅ Native macOS Frosted Glass (`NSVisualEffectView`) with `.ultraThinMaterial` cards
👁️ Live Glyph Preview ❌ None ✅ Real-time interactive preview of the menu bar glyph inside settings
🌍 Localizations ⚠️ 3 languages (en, zh) ✅ 17 World Languages with automatic system language detection
🔄 Auto-Updates ❌ None (manual download) ✅ Sparkle 2 framework + Ed25519 cryptographic signatures & GitHub Pages feed
🎨 Application Icon ❌ Generic placeholder ✅ High-resolution 256×256 Retina metallic icon (`AppIcon.icns`)
🤖 GitHub Actions CI/CD ❌ None ✅ Continuous automated builds (`build.yml`) & automated tag releases (`release.yml`)
🔋 Laptop Adaptive Ring ❌ None ✅ Smart handover to CPU / thermal load when plugged in and fully charged

Build from Source

Package the entire standalone DuoBar.app without opening Xcode.

# Clone the repository git clone https://github.com/vibe2code/DuoBar.git cd DuoBar
# Build, bundle, and ad-hoc sign DuoBar.app chmod +x ./tools/build-app.sh ./tools/build-app.sh
# Output ready in build/DuoBar.app open build/DuoBar.app
