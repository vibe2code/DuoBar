Three status indicators.
One 24-pixel glyph.

Battery arc. Network state. Volume dots. ReDuoBar consolidates your Mac’s essential indicators into a single, distraction-free menu bar item with an interactive popover.

Download for macOS GitHub (Open Source)
macOS 13.0+ · Apple Silicon & Intel · Universal Binary · Sparkle 2 Updates

Popover & Features

Clicking the glyph reveals a compact 304px native macOS popover with full system controls.

Wi-Fi & Keychain Autofill

CoreWLAN

Live network scanner with RSSI signal bars and WPA security status. Automatically retrieves saved passwords directly from your macOS Keychain, complete with show/hide eye toggle and persistent credential saving.

Core Audio Output Switcher

Core Audio

Instant audio device selector for AirPods Pro, built-in MacBook speakers, HDMI displays, and external USB DACs. Smooth volume slider with one-click instant mute.

Bluetooth & Radio Power

IOBluetooth

Toggle Wi-Fi and Bluetooth radio power directly from the popover without digging into System Settings. Inspect battery levels for connected peripherals.

Vibrant Liquid Glass Settings

AppKit / SwiftUI

Native macOS frosted glass window with real-time interactive preview of your menu bar glyph, icon scale adjustments, battery warning thresholds, and launch-at-login via SMAppService.

Sparkle 2 Auto-Updates

Sparkle

Cryptographically signed updates with Ed25519 keys, delivered directly through GitHub Releases. Automatic background checks with quiet in-place app replacement.

17 World Languages

Localization

Full native interface localization for English, Russian, German, French, Spanish, Japanese, Simplified Chinese, Traditional Chinese, Ukrainian, Italian, and 7 more languages.

Technical Specifications

Engineered for absolute efficiency. Zero electron wrappers, zero memory bloat.

Architecture Universal 2 Binary (Apple Silicon M1/M2/M3/M4 & Intel x86_64)

Build from Source

Compile the standalone ReDuoBar.app bundle directly from terminal without opening Xcode.

# Clone the repository
$ git clone https://github.com/vibe2code/ReDuoBar.git
$ cd ReDuoBar

# Build, bundle, and ad-hoc sign ReDuoBar.app
$ chmod +x ./tools/build-app.sh && ./tools/build-app.sh

# Launch the application
$ open build/ReDuoBar.app
