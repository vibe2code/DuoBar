Engineered for Modern macOS

Seamlessly blending Apple Human Interface aesthetics with powerful system control.

📶 Interactive Wi-Fi & Audio Switchers

No more clicking through System Settings. Scan Wi-Fi networks in real-time with signal bars and password prompts, and switch audio output devices across Core Audio with one tap.

🪟 Frosted Glass macOS Settings

Crafted with native NSVisualEffectView vibrant translucency and .ultraThinMaterial cards. Features live menu bar glyph simulation and granular scaling controls.

Why ReDuoBar Stands Apart

A feature-by-feature comparison against the original baseline.

Capability Original DuoBar (v1.0.0) ReDuoBar (vibe2code)
📶 Wi-Fi Network Picker ❌ Static name only ✅ Live CoreWLAN scan, signal bars, WPA locks, macOS Keychain password autofill, eye toggle & auto-save
🎧 Audio Output Selector ❌ Static label only ✅ Interactive Core Audio device switcher (AirPods, Speakers, HDMI, USB DAC) + 1-click mute
⚡ Wi-Fi Power Control ❌ None ✅ 1-click Wi-Fi module power toggle (On / Off) directly from the popover
🪟 Settings Window Design ⚠️ Basic opaque form ✅ Native macOS Frosted Glass (`NSVisualEffectView`) with `.ultraThinMaterial` cards
👁️ Live Glyph Preview ❌ None ✅ Real-time interactive preview of the menu bar glyph inside settings
🌍 Localizations ⚠️ 3 languages (en, zh) ✅ 17 World Languages with automatic system language detection
🔄 Auto-Updates ❌ None (manual download) ✅ Sparkle 2 framework + in-app auto-check toggle, Ed25519 signatures & GitHub Pages feed
🎨 Application Icon ❌ Generic placeholder ✅ Custom high-resolution Retina squircle icon (`AppIcon.icns` & 1024×1024 master PNG)
🤖 GitHub Actions CI/CD ❌ None ✅ Continuous automated builds (`build.yml`) & automated tag releases (`release.yml`)
🔋 Laptop Adaptive Ring ❌ None ✅ Smart handover to CPU / thermal load when plugged in and fully charged

Build from Source

Package the entire standalone ReDuoBar.app without opening Xcode.

# Clone the repository git clone https://github.com/vibe2code/ReDuoBar.git cd ReDuoBar
# Build, bundle, and ad-hoc sign ReDuoBar.app chmod +x ./tools/build-app.sh ./tools/build-app.sh
# Output ready in build/ReDuoBar.app open build/ReDuoBar.app
