# ReDuoBar Assets

Visual media assets for ReDuoBar documentation, release notes, and GitHub showcases:

- **`app-icon.png`**: 256×256 Retina application icon.
- **`duobar-popover.png`**: Clean interactive menu bar popover showcasing live Wi-Fi status, audio output device, volume slider, and battery status in English.
- **`duobar-wifi-picker.png`**: Expanded Wi-Fi network picker with live nearby networks, signal strength tiers, security lock badges, and 1-click Wi-Fi Power toggle.
- **`duobar-audio-picker.png`**: Interactive Audio Output switcher with Core Audio device list, active output indicator, and AirPods support.
- **`duobar-general.png`**: Native macOS Settings window (General tab) featuring Launch at login and Open on Hover interaction switches.
- **`duobar-settings.png`**: Native macOS Settings window (Menu Bar tab) with live simulated menu bar preview, icon size slider, and animation options.
- **`duobar-about.png`**: Settings window (About tab) displaying Version 1.2.0 • Build 4, license information, GitHub shortcut, and Sparkle update checker.
